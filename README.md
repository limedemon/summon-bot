# Summon Bot

Инлайн Telegram-бот для «саммонов»: набираешь `@имя_бота` в любом чате — появляется
список саммонов, выбираешь — бот роллит случайную карточку (по весам редкости) и
присылает её в чат с фото и опытом. Кулдаун — 5 минут на каждый саммон отдельно.

## Возможности

- **Инлайн-саммоны** — список саммонов через собаку, ролл сразу в чат.
- **Профиль** — фото-экран (генерируется ботом через Pillow): аватарка, ник,
  уровень (0–10, кривая опыта 5 → 8 → 10 → 15 → 25 → 40 → 60 → 90 → 140 → 210),
  health-bar опыта и health-bar собранных карточек, лучшая карта коллекции.
  При левел-апе бот пытается написать игроку личным сообщением (если тот
  хоть раз писал боту напрямую).
- **Индекс** — визуальный каталог карточек (тоже фото от бота): сетка 6×3,
  открытые юниты — с фото и шансом выпадения, закрытые — чёрная плашка с «?».
  Сначала общий индекс по всем саммонам, кнопками ниже — фильтр по конкретному
  саммону и листалка страниц, если карточек больше одной страницы.
- **Админка** (первый написавший боту — главный админ):
  - админы — добавить/удалить (по пересланному сообщению или ID);
  - саммоны — добавить/удалить;
  - редкости — добавить/изменить/удалить (название + шанс-вес в процентах,
    0–100 исключительно, до 20 знаков после запятой);
  - карточки внутри саммона — добавить/изменить/удалить (фото, название,
    редкость, опыт).

## Запуск

1. `pip install -r requirements.txt`
2. Задать переменную окружения `BOT_TOKEN` (токен от @BotFather).
   Строка подключения к PostgreSQL зашита в `config.py` (`DATABASE_URL`).
3. У бота нужно включить инлайн-режим через @BotFather (`/setinline`).
4. `python main.py`

Хранилище — PostgreSQL (таблицы создаются автоматически при первом запуске).

Фото профиля/индекса кэшируются в `data/thumbs` (создаётся автоматически) —
это просто ускоряет повторный рендер, можно спокойно чистить вручную.
Шрифты для рендера лежат в `assets/fonts` (DejaVu Sans, идёт в комплекте
с репозиторием, кириллица есть из коробки).
