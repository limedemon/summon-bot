# Summon Bot

Инлайн Telegram-бот для «саммонов»: набираешь `@имя_бота` в любом чате — появляется
список саммонов, выбираешь — бот роллит случайную карточку (по весам редкости) и
присылает её в чат с фото и опытом. Кулдаун — 5 минут на каждый саммон отдельно.

## Возможности

- **Инлайн-саммоны** — список саммонов через собаку, ролл сразу в чат.
- **Профиль и коллекция** — обычное меню `/start` с опытом и списком полученных карточек.
- **Админка** (первый написавший боту — главный админ):
  - админы — добавить/удалить (по пересланному сообщению или ID);
  - саммоны — добавить/удалить;
  - редкости — добавить/изменить/удалить (название + шанс-вес в процентах,
    0–100 исключительно, до 20 знаков после запятой);
  - карточки внутри саммона — добавить/изменить/удалить (фото, название,
    редкость, опыт).

## Запуск

1. `pip install -r requirements.txt`
2. Задать переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather;
   - `DATABASE_URL` — строка подключения к PostgreSQL (`postgresql://user:pass@host:port/dbname`).
3. У бота нужно включить инлайн-режим через @BotFather (`/setinline`).
4. `python main.py`

Хранилище — PostgreSQL (таблицы создаются автоматически при первом запуске).
